# TJ Rodriguez - Personal Data Dashboard

A dashboard that serves as a demonstration of my emerging abilities in JSON properties. This is also project 3 for the WRIT 40363 Fall 2026 class.

**Live site:** https://tjrod28.github.io/dashboard/

## Built with

- Semantic HTML
- CSS with design tokens and padding tokens
- JavaScript functions
- JSON text
- Git and GitHub Pages

## Notes

The accent color and font pairing were chosen in Lab 19. The goal of this project is to serve as a sample web development app to help me understand how to deploy JSON text along with JavaScript and CSS tokens. This project is also my first project involving a dark and light mode, which I am particularly proud of during its development. It is also the first project of mine involving a randomized quote block which was fun to create and see it shuffle through the random quotes I included. The quotes included range from inside jokes I have with friends to quotes from some of my favorite fictional characters. It is also important to note the weather displayed in the project serves as a sample and not an accurate reading of the weather during the days I spent developing this app.
